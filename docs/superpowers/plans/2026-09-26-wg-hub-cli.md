# wg-hub CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the personal scripts with a public, one-command Bash CLI (`wg-hub`) that provisions a WireGuard hub on a fresh GCP project and connects Linux/macOS machines and phones to it.

**Architecture:** An entrypoint `wg-hub` sources focused `lib/*.sh` modules (ui, state, os, gcloud, hub, peers) and dispatches `cmd_*` functions. Hub-side logic lives in two scripts copied to the VM: `hub/bootstrap.sh` (one-time idempotent setup) and `hub/wg-hub-peer` (peer add/remove/list/isolate, run as root). All external commands are called by name so tests can stub them through `PATH`.

**Tech Stack:** Bash 3.2+, WireGuard (`wg`, `wg-quick`), Google Cloud SDK, `qrencode`, bats-core, shellcheck, GitHub Actions.

## Global Constraints

- Bash 3.2 compatible: no associative arrays, no `${var,,}`, no `mapfile`, no `readlink -f`.
- `set -euo pipefail` in entrypoint and hub scripts; libs must be safe under it.
- shellcheck clean (default severity).
- No hardcoded project IDs, public IPs, keys, emails or home paths anywhere in the repo.
- Subnet `10.66.66.0/24`; hub `10.66.66.1`; clients from `10.66.66.2`; port UDP `51820`.
- Client config has no `DNS =` line; `AllowedIPs = 10.66.66.0/24`; `PersistentKeepalive = 25`.
- State dir `${XDG_CONFIG_HOME:-$HOME/.config}/wg-hub` (700), files 600. Overridable via `WG_HUB_CONFIG_DIR` for tests.
- VM: `e2-micro`, `ubuntu-2404-lts-amd64` / `ubuntu-os-cloud`, `--boot-disk-type=pd-standard` (free tier covers standard PD only), `--can-ip-forward`, tag `wg-hub`, name `wg-hub`.
- Project id format `wg-hub-<6 chars [a-z0-9]>`.
- `-y` / `WG_HUB_YES=1` auto-confirms prompts (never the teardown typed confirmation).

**Spec deviation (recorded here and in spec):** region suggestion uses the machine's timezone instead of measured latency. GCP front ends are anycast, so ping from the client does not reflect region distance without extra per-region endpoints; timezone is reliable and dependency-free.

**Note on code in this plan:** tasks specify interfaces and exact test cases; implementation code is written directly into the files during execution (single engineer, inline execution) rather than duplicated here.

### Task 2: OS detection and packages (`lib/os.sh`)

**Interfaces (produces):**
- `detect_pm` → echoes `dnf|apt|pacman|zypper|brew`; dies "Unsupported OS" otherwise. Reads `${WG_HUB_OS_RELEASE:-/etc/os-release}` `ID` then `ID_LIKE` words; `uname -s` = `Darwin` → `brew`.
  Mapping: fedora rhel centos rocky almalinux amzn → dnf; debian ubuntu linuxmint pop raspbian → apt; arch manjaro endeavouros → pacman; opensuse* suse sles → zypper.
- `sudo_cmd` → echoes `sudo` or empty when root.
- `pkg_install_cmd PM` → echoes the install command line for `wireguard-tools qrencode` (apt prefixes `apt-get update &&`).
- `ensure_packages` → no-op if `wg` and `qrencode` present; brew missing on macOS → die with https://brew.sh.
- `wg_conf_dir` → `/etc/wireguard` on Linux, `$(brew --prefix)/etc/wireguard` on macOS.
- `tunnel_exists` → 0 if `wg0.conf` exists in `wg_conf_dir`.
- `tunnel_write_conf` (reads conf on stdin, writes `wg0.conf` 600 as root)
- `tunnel_up` / `tunnel_down` → systemd `wg-quick@wg0` on Linux; launchd daemon `/Library/LaunchDaemons/com.wg-hub.wg0.plist` on macOS (PATH includes brew bin so brew bash runs wg-quick).
- `suggest_region` → from `${WG_HUB_TZ}` or `/etc/localtime` link target: America/{Los_Angeles,Vancouver,Tijuana,Anchorage}, Asia/*, Australia/*, Pacific/* → `us-west1`; America/{Chicago,Denver,Phoenix,Edmonton,Winnipeg,Mexico_City,Regina,Boise} → `us-central1`; else `us-east1`.

**Tests (`tests/os.bats`):** fixture os-release for fedora, ubuntu, debian, arch, opensuse-tumbleweed, linuxmint (ID_LIKE ubuntu), unsupported (`ID=plan9`) → error; stub `uname` → Darwin → brew; `pkg_install_cmd apt` contains `apt-get update` and `wireguard-tools qrencode`; `pkg_install_cmd brew` has no sudo; `suggest_region` for America/Los_Angeles, Asia/Tokyo, America/Chicago, Europe/Berlin, America/New_York.

### Task 3: Hub peer helper (`hub/wg-hub-peer`) and bootstrap (`hub/bootstrap.sh`)

**Interfaces (produces), all run as root on the hub, `WG_DIR` overridable (default `/etc/wireguard`):**
- `wg-hub-peer add NAME PUBKEY IP` → `wg set wg0 peer PUBKEY allowed-ips IP/32`; appends block `[Peer]\n# wg-hub: NAME\nPublicKey = …\nAllowedIPs = IP/32`; refuses duplicate name or IP.
- `wg-hub-peer remove NAME` → `wg set wg0 peer KEY remove`; deletes the block; unknown name → exit 1.
- `wg-hub-peer list` → lines `NAME IP HANDSHAKE_EPOCH` (0 = never) using `wg show wg0 latest-handshakes`.
- `wg-hub-peer used-ips` → one IP per line from conf.
- `wg-hub-peer isolate IP_A IP_B` → appends `IP_A IP_B` to `isolate.rules` (dedup), applies rules.
- `wg-hub-peer apply-isolation up|down` → for each rule, add/remove `iptables FORWARD -i wg0 -s A -d B -j REJECT` both directions (`-C` check before insert).
- `bootstrap.sh` → installs wireguard+iptables, installs `/tmp/wg-hub-peer` to `/usr/local/sbin`, creates hub key if missing, writes wg0.conf if missing (PostUp/PostDown call apply-isolation), enables ip_forward in `/etc/sysctl.d/99-wg-hub.conf`, enables `wg-quick@wg0`, prints `HUB_PUBKEY=<key>`.

**Tests (`tests/hub_peer.bats`, stub `wg` and `iptables` logging argv to a file):** add writes block and calls wg set; duplicate name rejected; duplicate IP rejected; remove deletes only that block and calls wg remove; remove unknown fails; used-ips lists IPs; list joins handshakes; isolate writes rule once and inserts 2 iptables rules; apply-isolation down deletes them.

- [ ] Write tests, run (fail), implement, run (pass), shellcheck, commit.

### Task 4: Client peers lib (`lib/peers.sh`)

**Interfaces (produces):**
- `validate_name NAME` → dies unless `^[A-Za-z0-9_-]{1,32}$`
- `next_free_ip` → reads used IPs on stdin, echoes first free `10.66.66.N` (N=2..254); dies "Subnet full".
- `keygen` → echoes `PRIVATE PUBLIC` (uses `wg genkey`, `wg pubkey`).
- `render_client_conf PRIV IP HUB_PUB HUB_IP` → prints config per Global Constraints.

### Task 5: GCP and hub provisioning libs (`lib/gcloud.sh`, `lib/hub.sh`)

**Interfaces (produces):** all use `$GCLOUD` (set by `find_gcloud`).
- `find_gcloud` → sets `GCLOUD` from PATH or `~/google-cloud-sdk/bin/gcloud`; returns 1 if none.
- `ensure_gcloud` → installs via `curl -fsSL https://sdk.cloud.google.com | bash -s -- --disable-prompts --install-dir="$HOME"` when missing.
- `ensure_auth` → `gcloud auth login` when no ACTIVE account.
- `gen_project_id` → `wg-hub-xxxxxx`.
- `ensure_project ID` (create if `projects describe` fails), `ensure_billing ID` (skip if `billingEnabled` True; 0 accounts → die with console link; 1 → auto; >1 → numbered menu), `ensure_compute ID`.
- `pick_zone REGION` → first zone from `compute zones list --filter=region:REGION`.
- `ensure_static_ip` → echoes address (reserve `wg-hub-ip` if missing).
- `ensure_firewall`, `ensure_vm IP`.
- `hub_exec CMD` → `gcloud compute ssh wg-hub --project --zone --quiet --command CMD`.
- `wait_ssh` → retries `hub_exec true` 10× with backoff 5,10,15… s.
- `bootstrap_hub` → `compute scp hub/bootstrap.sh hub/wg-hub-peer wg-hub:/tmp/`, runs `sudo bash /tmp/bootstrap.sh`, parses `HUB_PUBKEY=`.

**Tests (`tests/gcloud.bats`, stub `gcloud`):** gen_project_id matches `^wg-hub-[a-z0-9]{6}$`; ensure_billing with 1 account links it; with 0 accounts dies with message containing `billing`; with billing already enabled makes no link call; pick_zone returns first line; hub_exec passes project/zone from state.
